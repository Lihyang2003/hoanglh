# Portfolio Lê Huy Hoàng

- site/ là bản chạy được (HTML tĩnh). Mở site/index.html, hoặc đưa nguyên thư mục site/ lên GitHub Pages.
- build/cases.mjs chứa nội dung 5 case study, mỗi câu là cặp [tiếng Anh, tiếng Việt].
- build/build.mjs chứa trang chủ và khuôn trang case. Sửa xong chạy: node build/build.mjs
- site/site.css, site/site.js, site/lab.js sửa trực tiếp.
